# Three-minute demo

Beforehand, start the app with `npm start`, open `http://localhost:5173`, and use headphones and a microphone. Explain that the career information is not verified careers advice.

## 0:00–1:10: Discover

Start the conversation. Say: “I edit videos for my cousin's band and make sounds on my laptop. I don't like presenting.” Answer Wave's follow-ups naturally, including a preference and a practical barrier. When the profile appears, correct anything wrong and confirm it.

## 1:10–1:45: Explore the map

Point out a career that is less obvious than the original interests and explain the fit reason. Open a card, read a typical responsibility and a possible route, and point out the AI-information disclaimer. If the suggestions differ, use one that actually appears rather than promising a specific title.

## 1:45–2:45: Try a decision

Open an authored simulation if available: sound designer, biomedical engineer or game accessibility designer. Read the situation, choose a decision and show its consequence. If time allows, change the decision or continue to the second one. Explain that the simulation is an illustration, not professional training.

## 2:45–3:00: Close

Show the reflection or explain what it would cover. Mention that the app offers support resources if a disclosure is detected, but do not ask anyone to disclose personal experiences for the demo.

## Fallback

If microphone permission or voice connectivity fails, use the typing box and the same example answers. Text mode still needs the configured agent and network connection. If that connection also fails, use a previously recorded, consented demonstration if available; otherwise explain the interruption rather than presenting a live journey as working.

The page keeps session state in memory, but audio and messages are sent to ElevenLabs. Check the provider's retention settings before making privacy claims.
